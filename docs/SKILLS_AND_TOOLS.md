# Skills, plugins, MCP servers and sub-agents

What was available in Claude Code on 2026-11-17 (owner's user-level setup; this project has no project-level skills or agents), and when to use each. Skills are invoked with `/skill-name` or by asking Claude to use them. If a skill conflicts with `PROJECT_SPEC.md` or `CLAUDE.md`, **the spec wins** — say so and log it in `docs/DECISIONS.md`.

## Testing guidance by phase

There is **no dedicated automated-testing skill** installed. Follow the official docs bundled in `node_modules/next/dist/docs/01-app/02-guides/testing/`:

- Phase 1: Vitest unit tests for the data layer (published-only queries, money formatting).
- Phase 2: add **Playwright** (`playwright.md` in those docs) for the free-claim flow, magic link and download access; Vitest for token hashing and download-limit logic.
- Phase 3: tests for price tampering, invalid signature, duplicate webhook, failed payment and success flow (BUILD_PLAN Phase 3).
- `prototyping-testing:*` skills are for **user-research test plans**, not code tests.
