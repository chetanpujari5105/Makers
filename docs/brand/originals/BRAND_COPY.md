## About Fieldkit

Fieldkit is a curated collection of practical digital resources created to help people move from an idea to a useful result. Browse ready-to-use templates, guides, workbooks, prompt packs, design resources and project files. Each product should make it clear what is included, who it is for and how to use it.

Fieldkit is built by Chetan, an educator and digital creator. The goal is simple: make useful resources easier to understand, easier to start and easier to put to work.
